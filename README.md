# 🚀 Проект: SmartCrop & Encode (C++ / WinAPI)

## 📌 Общее описание проекта
**SmartCrop & Encode** — это легковесная утилита для быстрого создания, точного кадрирования, базового редактирования и потокового кодирования скриншотов в веб-форматы. 

Изначально проект был успешно реализован на **Delphi**, а в настоящее время находится в процессе **миграции на C++ (WinAPI / GDI)** в качестве пет-проекта для глубокого изучения низкоуровневой графической подсистемы Windows и оптимизации производительности.

---

## 🛠 Ключевые возможности и Жизненный цикл (Workflow)

1. **Мгновенный захват:** При запуске приложение автоматически делает полноэкранный снимок экрана и разворачивает его в рабочем графическом контексте.
2. **Двухуровневое кадрирование (Мышь + Клавиатура):** 
   * Быстрое выделение целевой области с помощью мыши.
   * **Попиксельная подгонка:** Использование курсорных клавиш (стрелок) для филигранной корректировки размеров и координат рамки выделения (режим регулировки переключается триггером).
3. **Изолированное редактирование:** По нажатию клавиши `ENTER` выделенный фрагмент вырезается из общего холста, и приложение переключается в режим встроенного мини-графического редактора, где доступно попиксельное дорисовывание и правка фрагмента.
4. **Конвертация и Экспорт «на лету»:** 
   * Оптимизация изображения с автоматическим сжатием и преобразованием в форматы **GIF** или **ICO**.
   * Кодирование бинарных данных графического фрагмента в строку **Base64**.
5. **Интеграция с буфером обмена:** Автоматическое оборачивание строки Base64 в готовые веб-теги (например, `<img src="data:image/gif;base64,...">` или `<link rel="icon" ...>`) в зависимости от выбранного пресета и отправка готового HTML/CSS-кода в буфер обмена Windows для мгновенной вставки в код веб-страницы.

## 💻 Технологический стек
* **Языки программирования:** Delphi (исходная версия), C++ (текущая версия).
* **Графический бэкенд:** WinAPI GDI / GDI+ (работа с контекстами устройств `HDC`, битовыми картами `HBITMAP`, манипуляции с Device-Independent Bitmaps).
* **Среда разработки:** Dev-C++ 5.11 / GCC.

---

## 🛑 Текущий статус и архитектурная задача
Проект находится в активной фазе портирования. На данный момент успешно реализованы механизмы захвата экрана, скроллинга больших изображений и логика попиксельного сдвига рамок выделения с помощью клавиатуры через состояния управляющего автомата (`g_pirog`). 

**Текущая задача:** Реализация отсечения (Clipping) и переноса Device-Dependent/Independent Bitmap из основного контекста памяти (`hdcMem`) во вторичное окно графического редактора по событию клавиши `VK_RETURN` (Enter) без привлечения ресурсов палитры дисплея.
